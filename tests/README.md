# Reference checksums

`reference_checksums.h` is generated by `capture_reference.sh` from the pinned
FFmpeg Bink 2 oracle:

- Repository: `https://github.com/mrtnmtth/FFmpeg-bink2`
- Commit: `f4904840e820bfd0fb8fbc22179b39dfdbd3a9e0`
- Base: FFmpeg `1f9b5fa5815c` (2022-05-07)

Regenerate:

```sh
BINK2_TEST_MEDIA="$HOME/Downloads" tests/capture_reference.sh
```

The script builds the oracle into `build/oracle/` when `FFMPEG_BINK2` is not
set. It writes per-frame FNV-1a checksums for the visible Y/U/V planes and
stores the first ten frames of each audio track in `tests/media/` so the
audio decoder can be compared with a one-LSB tolerance.

`sc13_01_partial.bk2` is genuinely truncated: the header declares 499 frames
but only frames 0–235 are complete. The golden array stops there.

## Filtered regression checksums

`filtered_checksums.h` is generated by `capture_filtered.sh` from
`bink2_dump --yuv` with the decoder filters on (the default). It holds
libbink2's own filtered output for the same frames as
`reference_checksums.h` (KB2f 0..235, KB2g 0..489, the KB2j fixture): it pins
behaviour, not a correctness reference, because the pinned oracle does not
implement the filters. `test_decode_filtered` compares against it; the KB2j
part always runs, the sample part skips (exit 77) without `BINK2_TEST_MEDIA`.

The KB2j entries equal the KB2j values in `reference_checksums.h`. The
fixture has no DC-only blocks, and its frame flags turn deblocking and the
residual edge filter off, so a filtered decode is byte-identical to an
unfiltered one, padding included. The KB2j array therefore pins only that
the filters leave this fixture alone; the filter stages are exercised by the
two sample files, by `test_filter_decode`, `test_block_info`, and by
`test_enc_inter`, whose clip has DC-only blocks.

Regenerate after building with `BINK2_BUILD_TOOLS=ON`:

```sh
BINK2_TEST_MEDIA="$HOME/Downloads" tests/capture_filtered.sh
```

A diff in this header means the filter output changed. Review the filter
change that caused it; do not regenerate to silence a failure.

## Encoded audio oracle

`test_enc_audio_oracle` encodes a short tone, decodes it with this library,
decodes the same file with the pinned FFmpeg Bink 2 build, and requires the
two PCM streams to differ by at most one LSB (the two decoders' float and
double transforms round some samples differently). Point `BINK2_ORACLE` at
the oracle binary:

```sh
BINK2_ORACLE="$PWD/build/oracle/FFmpeg-bink2/ffmpeg" \
  ctest --test-dir build -R '^enc_audio_oracle$' --output-on-failure
```

Without `BINK2_ORACLE` the test reports `Skipped` (exit code 77). It writes
temporary files in the current directory and removes them.

The oracle does not implement RAD's in-loop filters, so its output matches
`libbink2` only with the filters off (`bink2_dump --no-filters`). The
filtered output has no external reference; `filtered_checksums.h` pins it.

The decoded `ge_video_86l.bk2` luma spans 0–255 (not 16–235), so the
library's default RGB conversion is full-range BT.601. `sc13` fades in from
black; its first two frames are legitimately all zero.

The script also builds the pinned independent encoder
(`SBerda/bink2enc`, commit `dc40df9`) and writes
`tests/media/synthetic_kb2j.bk2`: a 32-frame 160x120 `KB2j` clip with four
slices. The encoder is used only as a fixture generator; no source from it
enters the library. Its frames extend `reference_checksums.h` with
`bink2_kb2j_checksums`.

## Audio validation

The pinned oracle's Bink Audio 2 path drops many packets with
"Incomplete packet", so its total PCM lengths are not a reliable golden.
`test_audio` instead compares the **first clean block** of every track
(1920 samples per channel) with a 4-LSB tolerance; the block bitstream and
lengths are checked exactly. A Bink 2 audio chunk can contain several blocks,
so the decoder loops until the chunk is exhausted.
